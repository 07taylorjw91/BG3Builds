# BG3 DIQ Build Guide (Android PWA)

Interactive Level 1–20 build guide, permanent bonus tracker, and best-in-slot gear checklist for Baldur's Gate 3 (*Difficulty, Immersion, Quality* modlist).

## Hosting & Installing on Android

1. Push all files in this folder (`index.html`, `manifest.json`, `sw.js`, and the three `icon-*.png` files) to the root of a GitHub repository.
2. In your repository, go to **Settings → Pages**, set **Source** to **Deploy from a branch**, select `main` (and `/ (root)`), and click **Save**.
3. Open your live `https://<username>.github.io/<repo-name>/` URL in **Chrome** (or Samsung Internet) on Android.
4. Tap the **Install App** button in the top bar (or open the browser menu `⋮` → **Install app** / **Add to Home screen**).

It will install onto your home screen as a standalone full-screen Android app with offline support.
